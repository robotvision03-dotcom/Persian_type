# رزرو نوبت نمایندگی خودرو

شبیه‌ساز تماس فارسی برای کارشناسی و نوبت نمایندگی. مشتری تماس می‌گیرد و منشی این‌ها را می‌پرسد:

1. سلام وقت بخیر. لطفا اسم خودروی خود را بگویی.
2. مدل خودروی شما چیست؟
3. کارکرد خودرو به کیلومتر.
4. نام و نام خانوادگی چیست؟

بعد تقویم دفتر را چک می‌کند و یک وقت از **دوشنبه تا جمعه، ۹ تا ۱۷** پیشنهاد می‌دهد. با گفتن «بله» مشتری به فهرست اضافه می‌شود.

- گفتار: شنوا کوچیک CTC
- فهمیدن جواب: **llama3.2:3b** در Ollama
- تقویم: شمسی، مثل تقویم رزرو قبلی

## اجرا

Ollama باید روشن باشد:

```powershell
ollama list
```

مدل لازم: `llama3.2:3b`

```bat
run.bat
```

سپس http://127.0.0.1:8000

می‌توانید پاسخ را تایپ کنید یا با **صحبت کن / توقف** بگویید.

## تست

```powershell
py -m unittest discover -s tests -v
```
