# رزرو نوبت نمایندگی خودرو

شبیه‌ساز **تماس زنده** فارسی برای کارشناسی و نوبت نمایندگی. یک دکمه «شروع تماس» میکروفون را باز می‌کند و مکالمه را به صورت نوبت‌کوتاه جلو می‌برد: منشی می‌پرسد، مشتری جواب می‌دهد، سؤال بعدی همان لحظه می‌آید — بدون دکمه صحبت/توقف.

اگر مشتری به سؤال اسم خودرو بگوید **پژو ۲۰۶** یا **peugeot 206**، مدل از همان نوبت پر می‌شود و منشی مستقیم کارکرد را می‌پرسد.

1. سلام وقت بخیر. لطفا اسم خودروی خود را بگویی.
2. مدل خودروی شما چیست؟ *(اگر در جواب قبلی آمده باشد، رد می‌شود)*
3. کارکرد خودرو به کیلومتر.
4. نام و نام خانوادگی چیست؟

بعد تقویم دفتر را چک می‌کند و یک وقت از **دوشنبه تا جمعه، ۹ تا ۱۷** پیشنهاد می‌دهد. با گفتن «بله» مشتری به فهرست اضافه می‌شود.

- گفتار: شنوا کوچیک CTC
- نوبت‌گیری زنده: تشخیص سکوت (VAD) روی مرورگر؛ هر مکث کوتاه یک جواب است
- پر کردن چند خانه در یک جمله: NLU محلی، بدون منتظر ماندن برای LLM
- تقویم: شمسی

## اجرا

Ollama برای کارهای دیگر لازم است ولی مکالمه رزرو بدون آن هم جلو می‌رود.

```powershell
ollama list
```

مدل پیشنهادی: `llama3.2:3b`

```bat
run.bat
```

سپس http://127.0.0.1:8000

«شروع تماس» را بزنید و جواب بدهید. همان دکمه در حین تماس «پایان تماس» می‌شود. اگر میکروفون نباشد، می‌توانید تایپ کنید.
