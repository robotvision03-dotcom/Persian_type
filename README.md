# خرید خودرو و رزرو نوبت بازدید

شبیه‌ساز تماس زنده برای **نمایشگاه فروش خودرو**. مشتری تماس می‌گیرد، نام خودرو را می‌گوید، و برای بازدید و خرید نوبت می‌گیرد.

- تقویم **شمسی** است. در هفته ایرانی **جمعه تعطیل** است و شنبه تا پنجشنبه از ۹ تا ۱۷ باز است.
- ساعت‌های خالی از همان جمله «سلام وقت بخیر. لطفا اسم خودروی خود را بگویید» روی صفحه دیده می‌شود.
- فهرست خودروهای موجود در ایران (ایرانی، چینی، کره‌ای، ژاپنی، اروپایی و …) با تطبیق فازی: اگر بگویید **سمن** و فقط **سمند** نزدیک باشد، همان ثبت می‌شود.

1. سلام وقت بخیر. لطفا اسم خودروی خود را بگویید.
2. کدام مدل را برای خرید می‌خواهید؟ *(اگر در همان جواب آمده باشد، رد می‌شود)*
3. خودرو صفر است یا کارکرد دارد؟
4. نام و نام خانوادگی چیست؟

سپس وقت بازدید پیشنهاد می‌شود. با «بله» نوبت در فهرست ثبت می‌شود.

- گفتار: شنوا کوچیک CTC
- تشخیص خودرو: کاتالوگ + پیشوند یکتا + فاصله ویرایش (بدون انتظار برای LLM)
- نوبت‌گیری زنده: تشخیص سکوت روی مرورگر
